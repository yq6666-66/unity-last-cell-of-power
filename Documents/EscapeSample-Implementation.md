# 电量与逃生单元实施基线

用户已批准单房电量、充电和逃生闭环。此前StealthSample保留。修改前完整备份位于同级LastCellOfPower-escape-baseline-20261111-225520，含哈希清单。

资源规则：100上限、35初始；基础耗1/s，实际水平移动额外.5/s；充电8/s，净7/s；两座南侧充电座无限储量。按住E交互，水平锁定但镜头可转。选中后锁定对象，距离1.8米及无遮挡保持有效。暂停/失焦取消，恢复必须先释放E。

北门终端开始要求48，连续3秒后扣45一次。中断归零，不返还基础消耗。门1秒滑开、完全开启后释放碰撞和动态导航障碍。出口中心x1、平台z6至8.4，玩家z>=6.8才判胜。错误优先于被抓、耗尽、逃脱；三种正常结局均R重开。

新增EscapeSample场景/Runtime/Editor，复用旧玩家、敌人、感知。玩家仅新增默认关闭的水平移动锁及实际位移观察，回归旧样本。新会话统一计时、UI、结局。构建独立目录；实际验收继续使用已授权的扫描码/相对鼠标事件。

## 场景读取事实

Unity实际模型北门根世界位置(-1,0,6.16)，北墙面板ENV_Wall_2m__N_-1在(1,0,6.16)。新场景将这两组件交换x位置，符合方案出口x1。门叶命名L/R与世界x左右相反，动画按实际世界左右排序，避免按名字导致关门。

充电座名字SW/SE也与世界x相反，但仍位于±5,-5，保留实际位置。FBX实例有100倍缩放和导入轴旋转，保留导入矩阵，不凭名字重复转轴。终端实际位于(-5.5,0,-2.5)，迁移到(2.8,0,5)并朝房间内，重建对应碰撞。

## 验证顺序

资源与交互边界自动检查；门洞、碰撞和导航契约检查；失败/胜利/重开优先级；独立Windows构建；正常输入充电、供电、穿门胜利，以及耗尽、充电被抓、供电中断、切窗恢复、重开；更新文档并打包哈希。
