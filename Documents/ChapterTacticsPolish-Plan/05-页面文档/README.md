# 05-页面文档

状态：整体方案参考；本次迭代不重复逐项确认。

| 界面/位置 | 内容与操作 |
| --- | --- |
| 运行HUD | 保留电量、目标、两条真实威胁、Q当前有效编号；沿用E提示区域显示装置编号/目的地和真实状态 |
| 单一区域短提示 | 激活、响应、拒绝、取消与完成结果；按既定优先级展示，不多处重复刷屏 |
| N01/N02操作台与扬声器 | 同号配对，目的地文字；可用一次、发声剩余、用尽及历史响应数 |
| S01两侧按钮 | 共享门状态：就绪、关闭中、闭锁倒计时、开启中、已用尽；占用反馈明确次数保留 |
| 首次情境引导 | 首次安全接近Noise/门显示最多6秒短说明；有Alert/Chase威胁时不弹长教学，仍保留即时操作提示 |
| 操作说明/帮助 | 三张简短规则卡：Q的4米/无遮挡/警觉追击/单目标；远端诱导和目视追击优先；门完全闭合才消耗及占用取消 |
| 暂停/设置 | 沿用现有操作与焦点规则，暂停不吞掉尚未读完的提示时间 |
| 结果页/重开 | 沿用本局统计；结束清操作提示，重开清响应与暂态，已看教学只保留至本次程序退出 |

无人响应时，信号仍持续显示“暂未收到响应”；结束为零才显示“本次未收到响应”。已有响应显示“曾响应N台”，不暗示机器人当前一定还在调查或玩家已安全。

门关闭中被占用的短提示明确为“关门取消：通道被占用 · 次数保留”。初始拒绝与成功闭合分开，开放后已用尽不显示可再次使用。
