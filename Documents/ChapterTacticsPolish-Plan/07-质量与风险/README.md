按三批执行：状态与反馈；标识与引导；整包交付。每批集中后台检查，只有具体失败、新变化或未解疑点才补测。纯逻辑、受控摆位、合成输入正常控制器、实际包与人工体验分开记录；不以空报告或退出码零代替检查。

已知风险：事件已提交但UI提前或延后、提示与教程竞争、暂停后提示被吞、重复监听/计数、编号对应错误、文字裁切、标牌重新引入叠面。分别用帧关联、优先级/生命周期断言、源资产保护、实际尺寸渲染及连续视角核对。

体验假设：反馈更清楚能减少把正常规则误认为故障。交付后只安排同一版集中试玩，任务为按自己的方式逃生，不要求用完装置或口头教授解法。未接触诱导/未发生门取消则对应项未验证；能理解但工具无价值属于下一轮摆位/平衡议题，本轮不顺带调参。
