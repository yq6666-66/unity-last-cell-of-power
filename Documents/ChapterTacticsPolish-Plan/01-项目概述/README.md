# 01-项目概述

状态：用户于2026-11-14明确回复“确认01-项目概述”，本项已确认，无修改意见。本项确认仅覆盖项目目标、范围、交付与验收原则，不代表其他章节或开工获准。

## 目标与使用对象

面向第一次接触本关卡、没有额外口头指导的玩家，让其理解诱导器控制哪里、是否曾有机器人响应、临时门为何拒绝或取消，以及Q只影响一台有效威胁，并据此自主选择使用时机。

有效基线为最新墙面修复版WarehouseTacticsWallFix。两台机器人、玩家3.4m/s、巡逻1.5m/s、追击3.0m/s、现有电量与一次性装置、地图碰撞/导航、供电后逃生目标均保持。5～8分钟是此前体验目标，不设最低时长、不为补时长增加等待。

## 本轮范围

1. N01/N02操作台与远端扬声器配对，明确目的地区域；状态灯配短文字，显示可用一次、发声中及用尽。
2. 只有机器人实际接受调查才去重记录响应；显示“曾响应N台”，未结束为“暂未收到响应”，结束仍为零才写“本次未收到响应”。不显示隐藏敌人位置、路线或当前状态，不把已启动说成安全保证。
3. 门反馈区分初始占用拒绝、关闭中占用取消、成功闭合与用尽。前两种明确次数保留，完全闭合才消耗。
4. 统一短提示优先级及暂停时钟，补充安全接近时的轻引导和诱导/门/Q帮助卡；保留现有双威胁HUD。

不新增任务链、敌人、武器、背包、关卡、难度模式、存档或网络服务，不调速度、电量、装置次数和AI判定。

## 交付与验收原则

交付独立Windows包、源码与反馈配置、变更说明、检查汇总、未验证项、素材许可和SHA-256；保留旧版本和备份。状态与反馈检查通过才能交付，开发中后台集中检查，最后同一版集中试玩。

工程完成的证据包括真实响应去重、门结果与次数一致、暂停/失焦/重开正确、三种分辨率无缺字溢出、静音仍能理解关键结果、正常控制器路线及Windows实际运行。玩家是否更理解、更愿意使用工具属于待试玩的体验假设，不预先宣称成立。
