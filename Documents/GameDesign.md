# 《最后一格电》完整第一关设计

ChapterOne的主题是一个可靠的应急能力、清楚的玩家界面与反馈，以及简洁的关卡收尾。保留已验收四区地图、一个敌人和宽松参数，入口为 `Assets/ChapterOne/Scenes/WarehouseChapterOne.unity`。

## 基础地图与玩法

地图内边界X/Z为-12至12，四区环通：西南维修起步区、东南货架区、西北设备区、东北装卸出口区。出生约(-8,0,-9)，终端约(-8,0,8)，出口约(8,0,12.16)。四连接口净宽3.2米，三处充电点和原碰撞／导航保留，起步区不设绝对无敌规则。

| 项目 | 当前配置 |
| --- | --- |
| 玩家与视角 | 3.4m/s，眼高0.9米，俯仰±80°，自身模型隐藏 |
| 电量 | 上限100、初始40，静止0.2/秒，实际水平移动额外0.3/秒 |
| 充电 | 充入8/秒，净增7.8/秒，上限100，储量无限 |
| 供电 | 门槛36，连续2秒完成后扣35一次；中断归零且不扣完成费 |
| 交互 | 相机附近选择，1.8米内且无遮挡；锁定后可转头，移动或松E取消 |
| 门与出口 | 供电后1秒滑开，完全打开释放阻挡，穿过局部出口区域才判胜 |
| 敌人 | 巡逻1.5m/s、追击3.0m/s，7米/90°感知，1.2秒警觉、1.5秒消退 |
| 捕获与搜索 | 已确认警觉后，0.65米无遮挡持续0.35秒捕获；最后目击点搜索总计最多6秒 |
| 结局优先级 | 运行错误、被抓、耗尽、逃脱；既有终局不被技能撤销 |

敌人不通过隐藏玩家实时坐标寻路。普通巡逻避开起步区，起步区仍可能被追入；所有原宽松参数保持，不因新增干扰而提高敌人速度。

## 应急干扰

| 项目 | 锁定规则 |
| --- | --- |
| 输入 | 新按下Q一次；按住不连发，暂停恢复先松Q |
| 目标资格 | 目标仅为Alert或Chase中的现有敌人 |
| 范围 | 水平距离不超过4米，感知锚点之间无实体遮挡，无需朝准星瞄准 |
| 门槛／费用 | 至少13电量；有效释放扣12一次 |
| 无效请求 | 无目标、遮挡、过远、冷却或不足电不扣费、不进正式冷却，只给简短提示 |
| 命中 | Disrupted持续2.5秒，Agent保持启用但停止移动、转向、感知及捕获；冷却15秒 |
| 与E关系 | 成功Q才取消交互并要求释放E；无效Q保持既有E交互 |
| 暂停／结局 | 停机、冷却、敌人及资源计时冻结；重开清空技能和统计状态 |

停机前若为Chase，恢复后仍真实感知玩家则继续Chase，捕获计时从零开始；看不见则搜索原最后目击点。停机前若为Alert，保留警觉值，再按真实可见性积累或消退。不额外赠送完整警觉窗口，不更新停机期间隐藏玩家的位置，也不新增声源调查系统。

会话顺序固定为：运行状态检查 → E准备 → 玩家移动 → Q扣费与命中 → 敌人更新与捕获 → 门和资源推进 → 耗尽／逃脱判定。只有同帧尚未成立的捕获可以被有效Q阻止。技能控制器是扣费、停机、冷却与成功事件的唯一提交点，UI和声音不改变结果。

## 玩家呈现

四区入口有非碰撞名称牌、编号与色带。开场说明可跳过；充电、终端和首次警觉提示跟随实际状态，重开不反复强制教程，暂停菜单可重看。引导提醒供电后保留撤离余量，不把36门槛说成逃生保证。

正式HUD采用uGUI＋TMP，显示区域、电量、目标、E交互、警觉及Q状态。开局、运行、暂停、设置、帮助、结算均有明确界面状态，只有开始／继续操作恢复游戏，滑条和其他点击不锁鼠标或恢复玩法。F1保留开发诊断。

设备高亮绑定整机Renderer，取消、暂停和结局时恢复原有属性块，不修改共享材质。敌人状态灯、巡逻／警觉／追击／干扰恢复、充电／供电／门与胜败声音依据真实事件或状态反馈；暂停和结局停止或暂停对应循环。静音时保留文字、图标和进度反馈。

设置只包含主音量、鼠标灵敏度和恢复默认，使用ChapterOne独立PlayerPrefs键；默认灵敏度继承原控制器。字体为随包Noto Sans CJK SC Regular，音效为原创机械／电子合成。声音不吸引AI，光照不提供隐身加成。

## 统计与收尾

RunStatistics只记录有效运行时间和成功干扰次数。RunSummary在结局时冻结一次，结果页显示结局、本局用时、余电及成功干扰次数；无效Q不计数，暂停与结算不计时。短淡入可跳过，R或再来一局重开。失败说明只引用实际状态，例如已供电后耗尽，不推断反应速度。

本轮不做挑战标签、历史成绩、排行榜、配音、对话树、动态音乐分层、相机接管过场或室外新关卡。旧四区与单房的场景／配置保留，新能力通过可选引用启用。
