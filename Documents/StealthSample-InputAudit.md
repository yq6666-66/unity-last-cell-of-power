# 历史输入核查

本记录只分析 2026-11-10 的已有证据，不代表新样本运行通过。

Run-BoundarySample-r2.ps1 在 focus 模式才注入 D 扫描码；idle 的 driver-result.json 无按键注入。Unit1Boundary/frames.jsonl 共 9698 行，起初约 5.279 秒静止，随后运行时动作出现 rightArrow 和 downArrow 等方向键控制并发生位移。连续两帧动作均为零时最大水平位移为 0 米。

探针仅记录 WASD 原始键状态，没有方向键原始状态。activeControl 不代表唯一当前按键，不能凭该字段重建完整键序列。项目级动作与运行时克隆同时启用不证明重复移动，运行时代码只消费自己持有的一份动作。

驱动初始 foreground=False，Unity 样本均 focused=True；驱动未持续记录系统前台窗口，无法用本记录判定失焦恢复。观测结束退出码 0 仅证明观测完成。

结论：已证实位移与方向键动作相伴；现有证据无法确定输入来自人、其他进程或底层事件。历史输入来源保持未定因。新样本验收应记录消费动作、设备、全部 WASD/方向键状态、Unity 焦点和系统前台窗口。
