# 第一人称潜行样本实施记录

用户已确认本方案并将其设为当前执行目标。现阶段尚未通过新样本验收。

## 基线与保护

工程使用 Unity 6000.3.28f1。原 Assets/Stage4 保留；新功能位于 Assets/StealthSample。备份为同级 LastCellOfPower-stealth-baseline-20261111-215032，含 112 文件及 baseline-manifest.json。新构建独立输出，不覆盖 WarehouseUnit1。

## 已定行为

单房，Windows，第一人称，无常驻小地图。出生 (0,0,-4) 朝 +Z，眼高 0.9m；移动 3m/s，WASD/方向键相对视角，斜向归一化，俯仰 ±80°。点击锁鼠标；Esc/失焦暂停全部玩法；恢复点击后等待移动输入归零。主相机隐藏自身模型。

敌人 Patrol/Chase/Search/Return/Caught 五态；巡逻 1.6m/s，追击 3.3m/s，视距 6m，水平视锥 90°。实体墙/货架阻挡视线。只在可见时更新最后目击点；丢失后到该点原地转向搜索 4 秒；返回被打断的巡逻目标。任何非终态可重新发现玩家。水平距离 <=0.85m 且无遮挡则捕获，不受视锥限制。Caught 冻结，R 重载当前场景。

F1 显示状态、目标、可见性、路径、最后目击点、焦点和暂停，绘制调试线。引用/导航/路径错误须显示并停止本局。

## 实施顺序

1. 核查历史 idle 输入记录，保存已知与未知证据。
2. 编写独立输入控制、感知、状态机与会话组件；通过序列化字段接线。
3. 使用 Unity Editor 从旧场景另存新场景，移除新场景内旧运行组件，接好第一人称相机与新运行组件；原场景不变。
4. 独立逻辑及 PlayMode 检查状态机、遮挡、导航、捕获、暂停与重开。
5. 生成新 Windows Development Build；正常键鼠验收移动、碰撞、完整状态流程、焦点恢复及连续三次重开。
6. 更新项目说明、进度和变更日志；交付构建、哈希、日志和影像，明确 PASS/FAIL/BLOCKED。

## 证据边界

旧构建通过不等于新样本通过；脚本坐标设置与焦点回调只算逻辑测试。历史 downArrow 输入来源未定因，不把双动作实例直接当作根因。无真实输入证据的运行项不能标 PASS。

不含两房接入、电量、充电、出口胜利、手机触控、额外敌人或对外发布。完成本样本后停止扩展。
